## Быстро

1. Распаковать `wrapper.zip` в `%AppData%\Roaming\EXBO\jvm_wrapper\`
2. Запустить `stalcraft-jvm-wrapper.exe` → лицензия → контакты
3. **INSTALL** → **VERIFY** → перезапуск лаунчера → игра
