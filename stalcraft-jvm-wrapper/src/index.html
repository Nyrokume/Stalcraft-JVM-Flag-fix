    Server blocking

    Current version uses Windows Firewall (outbound rules on ports 29450–29460). Administrator rights are required.

    Do not use WinDivert-based blockers together with ExitLag, GearUP or similar boosters — two stack interceptors conflict and break tunnels.

    Planned alternative: server-side MITM via backend-*.stalzone and /address_list API — minimal OS changes, compatible with boosters. See docs/server-blocker-architecture-ru.md.
